How to Use the Website
1. Year Selection Slider

At the top of the page, allows you to choose any year from 1960 to 2020.
Drag the slider to select a specific year. The map and the bar chart will update automatically based on the year you select.

2. Data View Selection

Dropdown menu on the control panel, which lets you choose between different data metrics for analysis:

Life Expectancy: Shows life expectancy at birth by country.
Deaths: Displays total deaths by country, year, and gender.
Population: Displays the population size of each country.
Death Rate: Displays the death rate per 1,000 people.

Select your preferred data type from the dropdown. The map and charts will update to reflect your choice.

3. Gender Filtering

Gender toggle buttons (Male, Female, or Total) in the control panel, allows you to filter data based on gender.
Choose between male, female, or total population data to focus on specific demographic groups.

4. Age Filtering

Age filter options in the control panel, allows you to filter data based on specific age groups (e.g., infants, working-age adults, elderly).
Select the desired age group for analysis. Note: The age filter does not apply to the life expectancy data, as life expectancy is a summary metric for the total population.

5. Interactive Views

World Map
A choropleth world map that visualizes the selected metric for each country. Countries are color-coded based on data values.
Click on a country to highlight it in the bar chart and line chart. Hover over a country to see exact values for given year.

Zoom and pan
Use zoom controls to explore specific regions in more detail (especially useful for smaller countries).

Bar Chart
Displays a ranked bar chart of countries based on the selected metric for the chosen year.
Click on a bar to add the corresponding country to the line chart.
You can choose to view the Top 10, Bottom 10, All countries, or Only selected countries.

Line Chart
Shows the trend of the selected metric over time for the chosen countries.
Click on a country in the map or bar chart to add it to the line chart for comparison.
Hover over a data point to see exact values for any year.

6. Animation

Play/Pause button
Automatically advances through the years, allowing you to see how the data changes over time.
Press the Play button to start the animation.
Press Pause to stop the animation at any point.
While the animation runs, tooltips will update in real-time.

7. Tooltip Information

On the map, bar chart, and line chart, displays detailed data for each country when you hover over a country on the map or a data point on the charts.
Hover your cursor over any country or data point to see the complete data for that year, including the exact value and any relevant details.

8. Reset
Reset button in the control panel, clears all selected countries in line chart.
